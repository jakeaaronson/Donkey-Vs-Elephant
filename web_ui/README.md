# web_ui — Donkey vs Elephant Comparison UI

Flask-based single-page application for comparing text generated by two
fine-tuned GPT-2 models: a Democratic "donkey" model and a Republican
"elephant" model.

## Quick Start

```bash
# From project root, with venv activated:
python -m web_ui.app
# Open http://localhost:5000
```

## Endpoints

| Route              | Method | Description                             |
|--------------------|--------|-----------------------------------------|
| `/`                | GET    | Serves the main comparison UI           |
| `/api/generate`    | POST   | Generates text from both models         |
| `/api/health`      | GET    | Model status and readiness check        |

### POST /api/generate

**Request body (JSON):**

```json
{
  "system_prompt": "You are speaking to constituents.",
  "topic_prompt": "Discuss healthcare policy.",
  "user_prompt": "Hello, ",
  "temperature": 0.9,
  "max_length": 150,
  "top_k": 50
}
```

**Response:**

```json
{
  "donkey": "generated democratic text...",
  "elephant": "generated republican text...",
  "prompt_used": "full concatenated prompt",
  "params": { "temperature": 0.9, "max_length": 150, "top_k": 50 },
  "demo_mode": false
}
```

## Demo Mode

If trained models are not found in `models/donkey/` and `models/elephant/`,
the app runs in demo mode — it returns placeholder text explaining that
models need to be trained. The UI displays a yellow banner when in demo mode.
